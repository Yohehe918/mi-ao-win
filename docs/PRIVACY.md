# 隐私与本地数据

米遥不包含遥测、广告 SDK、云端账号、内置 API 密钥或自动上传功能。
遥控器音频在内存中解码并转发到用户选择的虚拟音频设备，主程序默认不保存录音或转写文本。
语音输入软件如何收集和处理语音，遵循该软件自己的设置及隐私政策。

本机数据位于 `%APPDATA%\mi-ao-win`：用户配置、按键方案、连接/按键/错误日志，以及短期本地控制连接资料。
日志可能包含本机路径、蓝牙地址、设备标识与进程号。它们不会被自动上传；向他人反馈问题前应自行脱敏。
日志不记录普通电脑键盘输入文本，也不记录密码或语音转写正文。
增强功能只观察经过验证的 RC003 专用驱动宿主，不观察其他蓝牙键盘；需要用户确认管理员授权。

安装包和公开源码由干净的文件清单生成，不包含开发者的用户配置、诊断日志、录音、蓝牙地址或凭据。
卸载保留用户配置；需要完全清理时，可在退出米遥后自行备份并删除上述数据目录。
米遥不会修改语音软件的账号、网络设置或隐私设置。
