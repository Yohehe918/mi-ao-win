米遥 Windows 0.2.0

1. 运行安装程序，选择安装目录，完成后打开米遥。无需安装 Python。
2. 跟随首次设置：在 Windows 蓝牙里配对 RC003，按菜单键 + Home 进入配对。
3. 未安装 VB-CABLE 时，在首次设置点击安装，阅读原厂条款并确认管理员授权；必要时重启 Windows。
4. 启动语音输入软件，把麦克风设为 CABLE Output，模式设为按住说话。
   已验证的豆包 v0.9.2.7 可使用原生兼容模式。其他软件可录制其按住输入快捷键并应用。
5. 点击启用增强按键，并确认 Windows 管理员授权。接管成功后返回、音量、语音与 TV 原生事件由米遥处理。
6. 把焦点放到普通输入框，按住语音键说话，松手结束。确认能出字及按键正常后勾选确认并完成设置。

日常使用：
- 以后只需打开米遥。重复打开会显示原来的窗口，不会启动另一份。
- 关闭窗口会缩到托盘；右键托盘选择退出会同时停止增强后台。
- 在设置中点击设置与自检，可以重新检查依赖与连接；增强功能可以暂停、恢复。
- 点击遥控器图上的按键编辑单击、双击、长按。内置动作支持自定义快捷键录制。
- 新安装方向键为普通上下左右；已有用户的按键方案保留。
- 更新时先从托盘退出米遥，再运行新版安装包；用户配置保存在 %APPDATA%\mi-ao-win，安装与卸载均保留。

限制：
- 真机验证范围为 RC003 固件 2671、Windows x64；其他遥控器、固件和蓝牙适配器需要实际验证。
- TV 免按遥控器收音尚不可用，不承诺免按语音。请使用按住语音键。
- 豆包兼容接口不是公开稳定 API，当前只放行经验证的 v0.9.2.7；升级豆包可能需要重新适配。
- 米遥不提供语音识别模型。联网、账号和语音数据处理取决于你选择的输入法。
- 返回和音量事件捕获要求遥控器具有独立的 Windows 驱动宿主；共享宿主时会拒绝增强捕获并提示。

排错：
无法出字：查看首次设置状态，确认 CABLE Input/Output 已存在、麦克风选择正确、语音软件已启动且兼容。
增强接管失败：保持遥控器连接，重新启用增强并确认 Windows 授权；不要同时运行旧助手。
蓝牙断开：重新配对或在设置里点击手动重连。不要填写他人的蓝牙地址。
更新：下载新的安装包并安装；没有后台自动下载或静默升级。
